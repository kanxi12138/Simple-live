# 7.0.2 B站列表、抖音播放与闪退修复

## 原因与只读排查

- 手机 AAK_AN00 的系统退出记录和 DropBox 崩溃记录确认：7.0.1 在 2026-09-19 11:18:29、11:19:11 两次因 `PlatformException` 崩溃。异常路径为 `validateStream` → 播放网络拦截器 → OkHttp `AsyncCall`，属于后台线程异常逃逸，不是已证实的解码器崩溃。
- 使用现有已编译的抖音签名实现请求公开分类接口，响应包含 `pull-flv-*.douyinliving.com`、`pull-hls-*.douyinliving.com` 等地址。原名单遗漏 `douyinliving.com`。这证实合法候选地址会被误拦；历史堆栈没有具体域名，不能断言两次崩溃都来自这一域名。
- 对两个候选地址仅发 HEAD 请求，均返回 403，未取得后续重定向证据，也没有下载直播内容。不能据此声称播放成功或覆盖全部 CDN。
- 按 DTV 当前公开源码复现 B站列表：分类 86 / 父分类 2，第 1、2 页均返回 code=0、40 个房间；0/0 返回 -400。该结果是电脑端只读请求结果，不是手机界面验收。

## 修改

### B站

列表使用 DTV 对应 UA、Referer、匿名 Cookie 标记、HTTP/1.1、运行时 access_id 和列表签名。匿名标记及公开协议签名盐不是账号凭证；列表不读取或发送加密保存的账号 Cookie。搜索、详情、播放和弹幕继续使用各自的账号会话。

首页先选择有效分类，默认显示分类表首项“英雄联盟”，“默认分类”替代无效的全部列表入口。分类初始化不覆盖已有订阅选择；列表请求沿用取消和代次检查。

列表 -352 响应提供验证凭据时，显示官方验证入口。专用 WebView 加载官方 CaptchaLoader，用户手动完成验证码；无 Java 桥，禁用文件访问及混合内容，禁止主页面导航。原生侧仅轮询固定页面的本次结果，按随机标识和当前待验证对象匹配；返回结果只用于对应列表请求的一次重试。切分类、刷新或换平台后旧结果失效。取消、SDK 失败、超时或再次 -352 均停止，不自动循环。未提供验证凭据时明确报告无法提供验证入口。

验证码、会话及完整签名 URL 不落盘或写日志。关闭验证码页不等于成功。验证码流程未做交互验收。

### 抖音和共用播放器

补充实际响应证实的 `douyinliving.com` 域名；初始地址、HLS 子资源与重定向继续使用共用校验。校验失败改为 `StreamAddressException : IOException`，使 OkHttp/Media3 通过正常网络错误回调报告失败，不再抛出历史堆栈中的业务异常。

候选播放源按画质整理 SDK 主地址、备用地址与 FLV/HLS 映射，排除空地址及无法通过校验的地址，默认选择仍有有效地址的画质；同格式备用源有独立线路标识。播放错误区分地址、网络及解码问题，仅明确的登录错误显示登录入口。

审查共用播放器、网络回调、弹幕回调及换房释放：弹幕消息解码异常已在连接边界传递，连接失败及心跳协程由监听任务处理；退出取消 WebSocket 和心跳。此次未发现需要扩大修改范围的同类异常逃逸。诊断只记录被拒绝的域名和平台，不记录 URL 查询参数。
