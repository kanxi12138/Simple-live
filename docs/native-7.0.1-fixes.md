# 7.0.1 首页与全屏修复

## 斗鱼首页

根因是首页尚未选择分类时发送 `cate2=0`。只读请求复现：返回 error=1；使用分类接口返回的原样 `shortName=LOL` 后，返回 error=0、20 个房间。改为先加载分类再选择第一个有效二级分类；分类失败可手动重试，不发送占位 ID。“默认分类”替代不受该接口支持的“全部直播”。三级分类继续使用数字 ID。

分类加载完成时只在尚无选择的情况下设置默认项，不覆盖用户已点击的订阅。切换平台会取消旧分类任务；列表仍使用取消和代次检查，避免旧请求覆盖新选择。

## B站首页：已修改请求，访问限制仍未解除

根据官方直播分区页面的公开脚本，将全部直播与分类列表分别接入 `getListByArea`、`getList`，参数保持对应接口语义；移除固定列表签名盐和无关的 `/lol` 页面标识，使用运行时 WBI 参数。官方共享请求代码也使用 WBI，并将 -352 交给风控验证码处理。

游客 buvid 只在内存中补齐，不再写回或覆盖加密保存的账号 Cookie；获取过程使用互斥锁，避免并发创建会话。已保存的登录会话优先使用。首页识别 -352/-101 并提供官方登录入口；保存会话后仅刷新当前平台列表一次，不进行自动重试循环。

匿名环境使用本次参数和动态签名只读请求两个列表端点，均仍返回 -352。**B站恢复访问尚未证实，也不能将错误提示改善视为故障已解决。** 本次未使用用户登录凭证进行接口探测；登录后是否解除限制需要用户实际操作确认。

官方脚本依据：

- https://s1.hdslb.com/bfs/static/blive/live-region/static/js/221.391a2d3a.js（请求中间件、WBI 与 -352 处理）
- https://s1.hdslb.com/bfs/static/blive/live-region/static/js/511.193c4881.js（全部直播列表）
- https://s1.hdslb.com/bfs/static/blive/live-region/static/js/81.d56e5df2.js（分类列表）

## 全屏与设置浮层

移除占用视频外部高度的常驻控制栏，控制栏覆盖在视频上；点击视频显隐，播放时 3 秒自动隐藏，暂停、播放失败和设置打开时不自动隐藏。Compose 统一提供暂停/播放、刷新、画质、线路、音量、弹幕与全屏按钮，关闭 Media3 自带控制器以免双层控制。

设置在当前窗口内弹出：竖屏底部、横屏右侧，可滚动；返回键依次关闭设置、退出全屏、退出房间。设置窗口不再使用独立 Dialog，避免全屏打开设置时显示系统栏。全屏布局和方向共用显式状态，避免退出时被旧的横屏配置重新触发。系统栏仅在全屏隐藏，退出恢复。

播放器仍按播放源和刷新版本保留实例，控制层显隐、打开设置、切换横竖屏不重新创建播放器。视频保持原始比例，宽屏手机上的自然黑边仍可能存在。
