# 原生版代码审查记录

本记录记录 7.0.0 迁移时的静态代码审查；当时未执行平台 API 探测、真实直播播放或界面验收。7.0.1 的少量只读接口排查及修复见 [修复记录](native-7.0.1-fixes.md)。

## 已处理的迁移问题

- 斗鱼分类保留数字分类 ID 与 shortName 两种标识：三级分类查询使用数字 ID，二级直播列表使用 shortName，配置迁移保留对应信息。
- 虎牙兼容顶层 `vList` 和 `data.vList`；WUP 支持标准应答和请求式应答、简单/嵌套 TUP 映射，令牌按 CDN 与流重新获取。
- B站保留短房间号解析、运行时 buvid、WBI 和 getDanmuInfo 签名；账号 Cookie 不进入视频 CDN 请求。
- 抖音移除旧列表中的固定会话 Cookie，改用运行时 Cookie；固定房间号与临时直播 ID 分开处理。弹幕根据 msg 类型处理 Protobuf、gzip 与 ACK。
- API 请求有超时和平台并发限制；直播请求取消总时长限制，仅保留连接与读取超时。视频重定向逐跳校验平台 CDN 域名。
- 切换平台、搜索及房间时取消旧任务，并使用代次标识阻止迟到的结果覆盖新页面。播放器销毁时释放 ExoPlayer，弹幕任务取消时关闭连接和心跳。
- 关注刷新在存储锁内重新读取条目，仅更新房间信息，避免重新创建已取消关注的主播或覆盖分组、备注、置顶变更。
- 导入校验在写入前完成；Room 保存回滚日志，使 Room 与 DataStore 之间的中断可在下次启动恢复。登录凭证不参与导入导出。
- 登录 WebView 无应用 JS 接口，只允许官方 HTTPS 页面导航；完成后加密保存 Cookie 并清理 WebView Cookie。平台响应、登录凭证和完整签名 URL 不写入日志。
- 更新下载限制 HTTPS GitHub 发布域名、包大小和完整长度；安装前再次核对包名、新版本和签名。
- 原生工程明确排除旧 JNI 目录，防止残留 `libdtv_lib.so` 混入 APK。

## 保留的运行验证限制

四平台公开接口、反自动化策略、签名运行兼容性、弹幕连接、具体手机的视频解码和页面交互未做运行验收。成功打包和安装只说明编译与安装流程通过，不代表这些功能经过实测。
