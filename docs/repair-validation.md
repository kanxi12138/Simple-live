# 5.2.2 仓库修复验证

## 定向验证入口

从仓库根目录运行；不依赖真实直播间，不增加测试框架。

```powershell
node scripts/test-repairs.mjs
powershell -ExecutionPolicy Bypass -File scripts/test-android-sync.ps1
python scripts/test-install-policy.py
cargo test --manifest-path core/Cargo.toml --lib tests:: -- --test-threads=1
```

Kotlin 校验需要设置 `JAVA_HOME`，并使用已有 Gradle 缓存中的 Kotlin 2.0.21 编译器。该入口提取生产 APK 身份校验函数，运行包名、版本及签名集合的正反例；不启动手机安装器。

## 覆盖范围

- 配置：旧格式导出往返、已识别键内部结构拒绝、未知键忽略、存储失败回滚、回滚失败后的同页面恢复、Cookie 保留。
- 屏蔽词：逐条过滤不读取存储、保存后缓存更新、跨窗口同步、保存失败保留旧缓存。
- 诊断：只输出固定类别及数字错误码，不返回原始 URL 或凭证文本。
- 更新：允许的 HTTPS 域名、端口及跳转次数；本地 HTTP 服务模拟完整下载、截断、超量、响应超时、响应体停顿、写入失败、替换失败；失败清理临时文件并保留原文件；互斥锁拒绝并发下载。
- HLS：4200 个连续历史分片、资源 ID 稳定、当前资源保留、两分钟淘汰宽限、容量超限不部分提交、非法清单不部分注册。
- B 站弹幕：本地 WebSocket 模拟连接超时、认证拒绝、后续候选成功、认证等待超时及取消；WSS 域名和端口限制、认证包解析。真实房间号用于认证、原请求房间号用于事件，通过调用链静态核对。
- 安卓同步：临时 Git 仓库核对保存源码向生成目录复制、生成文件保留、本地配置排除、无效目录拒绝。

## 构建与交付边界

构建前执行 `npm ci`，然后按 `docs/build.md` 完成前端生产构建、核心与安卓源码同步、Rust arm64 编译及 release APK 打包。保留版本 `5.2.2 / 5002002`、包名及现有签名。

APK 核验后通过 ADB `install -r` 覆盖安装，保留应用数据。签名不兼容则停止，不卸载。

以上验证不等于真实平台兼容性验收：没有手机长时间播放、真实弹幕收发、真实平台风控或应用内完整更新安装流程实测；系统 APK 解析与安装器调用由 Android 发布编译和 ADB 安装分别覆盖其有限范围。
