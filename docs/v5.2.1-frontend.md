# v5.2.1 前端优化

- 版本：5.2.1，Android versionCode：5002001。
- 路由页面改为动态导入，保持名称、参数及 KeepAlive 配置。
- 公共图片组件保留加载期间布局，使用异步解码，忽略旧图片事件；直播列表前两排立即加载，后续图片原生懒加载。搜索结果和自定义源封面也使用懒加载。
- 移除图片占位的持续动画和卡片常驻合成提示，取消全元素主题过渡，减轻导航及关注列表背景模糊和主题阴影。
- 首页分类、搜索、关注、设置与迁移、自定义源和播放器信息沿用暖色主题，统一背景、边框、焦点、状态颜色；减少动态效果设置限定在界面元素，不改变弹幕动画。
- 保留直播卡片尺寸、排列、业务逻辑、路由缓存、刷新及滚动机制；Rust 和 Android 只更新版本信息及构建产物。
