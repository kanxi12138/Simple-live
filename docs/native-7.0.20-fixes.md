# Android 7.0.20 斗鱼画质修复

版本：`7.0.20 / 7000020`。

## 问题与修改

- 房间 6657 请求原画档位 `0` 时，匿名请求实际返回蓝光4M档位 `4`，原界面仍显示“原画1080P60”。修复前实测为 1920×1080、约 30 帧/秒，无解码掉帧。
- 取流接入斗鱼当前官方网页使用的 `getH5PlayV1` 和动态签名参数；画质列表与播放请求采用一致参数，不再强制开启导致降档的 `ive=1`。
- 设置页增加斗鱼官方登录入口，并适配官方桌面登录页在手机上的显示。用户主动确认后，账号会话沿用现有加密存储；取消或未取得账号会话时保留原凭证。
- 仅斗鱼官方取流请求携带对应登录会话，播放地址及 CDN 请求不携带账号 Cookie。
- 根据平台实际返回的档位和线路更新播放选择与偏好。已选择的画质被降档时显示提示，不再把请求档位当作实际画质。
- 使用既有有大小上限的本地诊断记录采集分辨率、视频时间戳帧率与渲染计数，不记录签名、Cookie、完整播放地址或视频内容。
- 移除此次替换后不再使用的斗鱼旧签名方法；公共平台接口、数据库和配置格式不变。

## 验证

- 修改的 Kotlin 与 Gradle Kotlin 文件通过语法解析；release 构建成功，跳过 lint，未运行全量测试或独立类型检查。
- 同一房间匿名状态返回档位 `4`；用户完成官方登录后，请求和返回均为档位 `0`。
- 最终安装包全屏播放约 160 秒，分辨率为 1920×1080，依据视频呈现时间戳测得约 60.00 帧/秒，最后累计渲染 9,588 帧、丢弃帧与跳过帧均为 0。启动后采样均处于正常播放状态。
- 已确认登录状态在覆盖安装后保留，重新进入房间仍能请求到原画档位。
- 低画质切回、切换线路的专项流程未完成，未宣称通过；随后用户确认使用无问题并要求推送代码。
- 保持现有 release 签名覆盖安装，保留应用数据；手机安装包与交付 APK 的 SHA-256 一致。
