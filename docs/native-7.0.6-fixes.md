# 简直播 7.0.6 八项问题修复

日期：2026-09-20。包名：`com.simplelive.nativeapp`。版本：`7.0.6 / 7000006`。

## 修改与审查结论

本轮依据《审查报告-7.0.5.md》修复八项问题，并将用户反馈的弹幕滚动卡顿纳入第八项。下表为代码控制流审查结果，不是手机功能实测结果。

| 项目 | 修改 | 已审查的边界 |
| --- | --- | --- |
| 1. 登录取消覆盖凭证 | 只有主动点击完成才读取候选 Cookie。B站要求账号会话字段 SESSDATA，抖音要求 sessionid、sessionid_ss 或 sid_guard；只有访客字段时保留原凭证。取消、返回、Activity 销毁不保存。写入失败回滚内存中的原加密值。 | 完成与取消分流；空/访客 Cookie；保存失败；全局 Cookie 异步清理结束前保持登录窗口互斥，B站验证窗口也等待清理完成才回调。 |
| 2. APK 下载总超时 | APK 下载取消通用 35 秒 callTimeout，保留 15 秒连接、25 秒读取超时，以及下载体积、HTTPS 域名和包身份校验。 | 正常慢速下载不会仅因超过 35 秒被结束；读取中断仍有超时；读取循环及提交安装包前检查取消。 |
| 3. 更新状态和并行下载 | 更新状态、进度、候选版本、已下载文件与任务归 ViewModel 所有；SettingsScreen 订阅 StateFlow。下载器使用 applicationContext，进程内共享 Mutex 保护下载与恢复检查。 | 切页不丢任务和安装入口；重复点击被任务门禁阻止；多个下载器不能并行改同一文件；进程重启只恢复通过包名/递增版本/签名校验的完整 APK，临时文件不作为安装入口。 |
| 4. 搜索串页 | 新增已提交的 SearchQuery 快照，独立于输入框草稿。分页使用快照，提交搜索重置结果、页码及请求代次。 | 搜索 A 后编辑 B 再分页仍请求 A；提交 B、切平台或搜索模式会取消旧查询；空查询取消旧请求并清空结果；迟到结果不能覆盖新查询。 |
| 5. HTTP 错误与登录入口 | PlatformException 分别保存业务 code 和 httpStatus。通用请求及抖音访客会话请求保留 HTTP 状态。支持登录的平台在 HTTP 401 或现有明确会话错误 -101 时提供入口。 | 403 提示拒绝访问、429 提示请求频繁，不自动视为未登录；斗鱼/虎牙不能误打开 B站登录；弹幕错误包装保留真实 HTTP 状态。 |
| 6. 关注排序 | 在当前可见关注中寻找同分组、同置顶层级的相邻项；事务提交前重读记录并核对分组、置顶及原位置。 | 分组交错、平台/开播筛选、置顶分层；边界按钮禁用；已删除、移动或变更位置的过期操作不再写入；隐藏项不参与交换。 |
| 7. 斗鱼分类请求竞争 | 子分类有独立 Job 和代次。关闭面板、切平台、切父分类、返回全部分类和离开首页时取消旧请求。 | 成功和失败回调均检查当前代次/平台；迟到回调不再写入其他分类面板或显示旧错误。 |
| 8. 弹幕跳行与绘制开销 | 独立原生 Canvas 显示队列，入场缓存消息 ID、轨道、文字宽度、开始时间及持续时间；Choreographer 按帧时间计算绝对位置。 | 旧消息过期或列表淘汰不会改变存活消息的轨道；字体/区域/模式/尺寸变化统一重建，透明度即时生效；退出、后台、禁用、View 脱离时停止帧回调并清理，重新附着可恢复接收。 |

账号会话字段检查只用于拒绝空/访客会话，并不证明账号凭证当前有效。因此保存提示为“会话已保存，登录状态待确认”，本轮没有进行平台账号登录验收。

## 弹幕行为与性能修改

- 不再每帧重新过滤历史列表、分配轨道数组或测量文字；动画帧仅处理到期项、计算坐标和绘制缓存文字。
- 接收侧每 50 毫秒批量更新列表和投递屏幕消息，避免每条消息都复制历史列表、推送页面状态。接收缓冲最多 512 条，列表保留最近 200 条；屏幕显示队列独立，最多 512 条。
- 保留稀疏/适中/密集设置，密度控制消息入场频率；轨道拥挤时按用户选择允许重叠，轮流复用轨道，不等待空轨道形成积压。屏幕密度筛选不会删除列表消息。
- 显示队列不重放历史消息；关闭弹幕、返回前台或重新进入房间时只接收之后的消息。消息文本中的换行符在屏幕绘制时转为空格，列表保留原文。
- 每条弹幕入场后轨道固定，解决已从源码确定的“早期消息过期导致后续弹幕突然换行”。卡顿针对已知绘制与状态更新开销优化，未采集手机帧率，不能宣称已经实测达到特定帧率或完全消除所有卡顿。
