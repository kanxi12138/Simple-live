# 隐私与本地数据

本说明对应简直播 Android 原生版 7.0.2。

设备直接访问第三方直播平台的 API、图片、视频 CDN 和弹幕服务器；平台会收到必要请求参数、网络地址及该功能所需的会话信息。应用不运行开发者直播中转服务，不提供广告、分析或行为跟踪 SDK。

检查更新、下载 APK 和项目主页会访问 GitHub 及其发布资源服务。APK 更新下载不属于直播下载。

关注、分组、排序、置顶和分类订阅保存在本机 Room 数据库；主题、音量、画质、线路、弹幕和屏蔽词保存在 DataStore。弹幕消息仅保留在内存中，不上传给开发者。

官方网页登录使用专用 WebView。登录时第三方网页可能使用自己的 Cookie、网站存储和网络服务。关闭登录页后，应用将获取的 Cookie 使用 Android Keystore 支持的 AES-GCM 加密保存，并清理 WebView Cookie、网页缓存和网站存储。登录页无应用 JavaScript 桥。

B站安全验证使用独立的官方验证码页面，加载 B站官方验证码 SDK；该 SDK 及其验证码服务可能处理完成验证所需的设备和网络信息。页面不注入应用已保存的账号 Cookie，不提供 JavaScript 到 Java 的接口。应用只读取本次验证码的结果，在内存中用于对应列表请求的一次重试，不保存或记录验证码结果；关闭页面会清理其 Cookie 和网站存储。

登录凭证仅用于对应平台 API 和必要的弹幕认证，不发送给其他平台、视频 CDN 或更新服务，不写入配置导出或应用日志。可在设置中退出平台登录。应用没有自动读取旧版应用的私有数据。

主动导出的配置包含关注、分组、订阅与偏好，请自行保管；不包含 Cookie、缓存或直播源。导入会替换可迁移配置，导入前会进行校验，并保存用于中断恢复的本地回滚记录。

应用禁用 Android 自动备份。卸载原生应用会删除其私有数据，已由用户导出到其他位置的文件不会随卸载删除。手机上旧包名 www.sp.com 的应用和数据不受本次新应用安装影响。
